### git操作顺序
1. init
2. add
3. commit
4. branch
5. merge
6. reset
7. push
8. revert
9. push 
### 常用命令
| 命令 | 作用 | 使用时间 |
|---|---|---|
| `git add .` | 添加修改到暂存区 | 修改完成代码并保存后 |
| `git commit` | 保存一个版本 | 暂存后 |
| `git log` | 查看提交记录 | 查看提交内容时 |
### 示例
```bash
git revert --no-edit HEAD
git push
```
