# 修改观察现象 

## current_led = 1U 改成 2U，观察从哪颗 LED 开始；
> 修改后，从第二颗LED开始亮

## BEEP_MS 从 120U 改成 300U，观察蜂鸣器响声长短；
> 修改后，蜂鸣器响声变长

## delay_ms -= 20U 改成 += 20U，看速度变化方向；
> 修改后，速度变化方向和原来相反

## 删掉或改掉 beep(BEEP_MS) 的调用，观察程序行为。
> 修改后，一个循环后蜂鸣器不再响

    /* while 循环：条件成立就反复执行 {} 里的代码 */

    while(current_led <= led_count)

      blink_led(current_led, current_led, delay_ms);

    /* if / else 判断：让延时每次变快一点，到 100 后重新回到初始值 */

    }

      delay_ms = DELAY_MS;
    }
  }
